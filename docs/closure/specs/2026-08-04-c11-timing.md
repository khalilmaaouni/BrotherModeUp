## Summary

C-11 root cause confirmed in tools/test_bm.py:3630-3705: TestLoop12RedactionIsLinearInInputSize._time() takes exactly ONE wall-clock sample per call, and both test_quadratic_blowup_is_gone (line 3636) and its sibling test_a_run_of_underscores_does_not_blow_up_either (line 3667) build their ratio from one small and one large call. The comment claims noise cancels across both samples; that only holds if the SAME noise lands on both, and a stall on just large inflates the ratio while small is floored at 0.001 and cannot absorb it. Matches the CI failure in the register (30818827958, one leg of eleven, unchanged re-run passed).

Fix: change _time() itself (one place, fixes both call sites) to take samples=5 and return the MINIMUM. Minimum-of-N is standard: noise only ADDS latency, never removes it, so the minimum converges on true unloaded cost. 5 samples needs a stall on ALL 5 draws at one size and NONE at the other to move the ratio, exponentially less likely than the single-sample rate that already failed CI, while adding well under 1s per real-test call.

Defect detection preserved: the comment records reinjecting the pre-LOOP-12 UNBOUNDED key=value pattern (SECRET_PATTERNS index 8 in bm_telemetry.py, the 0,40-bound entry with bound removed) produced 15.6x on these sizes, nearly double the 8.0 threshold, so it survives min-of-5.

New adversarial test, test_calibrated_reinjecting_the_quadratic_key_value_pattern_reproduces_the_blowup, placed before class TestLoop12PairedArtifactsAreRedacted. Follows this files monkeypatch style (save, reassign, restore in finally, matching a calibration test at line 1560, not unittest.mock which this file never imports). Swaps SECRET_PATTERNS index 8 for the unbounded pre-fix regex, reuses the SAME 8000/32000 char texts, asserts ratio >= 8.0.

SIBLING with the identical single-sample RATIO shape: only test_a_run_of_underscores_does_not_blow_up_either, fixed for free by the shared _time() edit. Confirmed via grep: no other file defines _time, no other ratio-based assertLess exists.

WEAKER siblings (single-sample, ABSOLUTE ceiling not ratio, generous, lower priority, out of scope): test_redaction_of_a_large_input_stays_under_the_ceiling in test_bm.py (10.0s), test_mask_absolute_paths_stays_linear_on_long_input in test_bm_store.py (2.0s), test_decision_is_cheap_with_a_realistic_fence in test_bm_fence_hook.py (amortized over 50 calls). Replacement:

```
    def _time(self, text, samples=5):
        # C-11: a single wall-clock sample is exposed to one bad scheduling
        # stall landing on it alone, which is exactly what moved the ratio
        # below on CI run 30818827958 (one leg of eleven, unchanged re-run
        # passed). Minimum-of-N is the standard microbenchmark estimator:
        # noise can only ADD latency to a sample, never remove it, so the
        # minimum across several independent samples converges on the true
        # unloaded cost of the call. 5 samples means a stall has to land on
        # every single draw at one size and none at the other to move the
        # ratio, which is exponentially less likely than the single-sample
        # base rate that already produced a CI failure, while keeping the
        # added cost small (the largest text here is 32000 chars, on the
        # order of 0.2s per sample when linear, so under ~1s added per call).
        import time
        best = None
        for _ in range(samples):
            start = time.time()
            bm.redact(text)
            elapsed = time.time() - start
            if best is None or elapsed < best:
                best = elapsed
        return best
```

    def test_calibrated_reinjecting_the_quadratic_key_value_pattern_reproduces_the_blowup(self):
        # CALIBRATION for the two tests above, C-11's required adversarial
        # test. Put the pre-LOOP-12 UNBOUNDED key=value pattern back onto the
