# Pilot evidence, one participant

- Pilot id: P1 to P5 (never a name or handle in the committed summary)
- Group: solo founder or non-technical builder, or individual contributor
- Date, BrotherMode version and commit installed, operating system,
  Python version
- Install path used: the public instructions as written, yes or no
- Install outcome: success first try, success after retry, or failed at
  exactly which printed step
- Minutes to first useful artifact (measure 2)
- The nine measures, verbatim as the pilot answered them
- Every point where the pilot asked a human anything, with what was missing
  from the page that made them ask
- Every failure, as the pilot described it, plus the issue link if filed
- Final outcome: completed the fixed task, completed with recovery, or
  did not complete
- The pilot's own words, one paragraph, unedited except redaction

Redaction rule before anything is committed: no names, no handles, no
machine paths containing a username, no personal project content, no
secrets. The redaction is done by a human reading every line, not by a
pattern match alone.
