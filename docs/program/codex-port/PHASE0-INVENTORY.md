### What Phase 1 must decide for each ledger item

Per the spec's own Phase 1 tasks (route path resolution through one helper
accepting `PLUGIN_ROOT` then compatibility variables then an explicit error;
never silently fall back to cwd for security-sensitive paths), every
`.claude/`-literal and `${CLAUDE_PLUGIN_ROOT}` line above is a candidate for
that helper. The fence's worktree-identity rule in `bm_store.py` and the
settings-floor checks are the two highest-risk items: both are
security-relevant (single-writer enforcement, permission-floor refusal) and
neither may silently degrade if ported carelessly.
