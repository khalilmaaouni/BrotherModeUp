BrotherME for Claude Code

The plugin that refuses to say done

BrotherME blocks a second writer on a file another session already claimed, and it refuses the word done until a check runs after the last change and passes. On Claude Code both are machinery, not advice.

Install is two lines. You need Claude Code and Python 3.9 or newer, nothing else. Open Claude Code and type them one at a time.

/plugin marketplace add khalilmaaouni/BrotherModeUp
/plugin install brotherme

Then type /brotherme-help. If it answers, you are installed.

Status, 2026-08-04

  • Verified: the refusal above, and the test suite guarding it, run on Claude Code today. 1573 tests across 15 suites, all green, and the same suite green on every CI job across three operating systems and both supported Python versions.
  • Real use exists; measurement does not. An earlier version of this page said nobody had used this for real work, and that was wrong: the author has used it daily for weeks and other people run it on their own machines. What is missing is the MEASUREMENT, not the usage. There are no counted projects, no recorded failure or rework rate, no observed outside participant, and no comparison against working without it. Real use does not become a graded result by being real.
  • Claude Code only. Other AI tools get advisory instruction files, not enforced gates, and the gates fail open rather than lock you out.
  • The shell is only partly covered. With BM_FENCE_MODE=enforced set, an obvious destructive command aimed at BrotherMode's own store is refused. That is a narrowing, not containment: it matches literally rather than parsing your shell, so a path built at runtime is not caught, and there is no operating-system sandbox. docs/KNOWN-LIMITS.md lists exactly what it misses.
  • Release 2.0.0, the first public release. The install pages pin it, the repository carries exactly one branch, and the changelog ends with what is still unproven rather than claiming it. Type /brotherme-update to check whether a newer release has shipped.
  • Pick one install path. The plugin or the older clone, never both; a machine carrying both runs everything twice.

What makes it different

Eight mechanisms, one line each. The first two are machinery on Claude Code, gates that refuse; the other six are working discipline that the machinery records and the tests hold in place. This section is kept current by rule: any release that changes a feature updates it in the same change.

One writer per file. A claim is recorded before work starts, and the gate you just watched refuses the second writer while that claim lives.
Proof or it is not done. Done requires a check that ran after the last change and passed, and delivery writes that evidence into a packet.
The guided loop. The strongest model plans and judges, cheaper helpers execute, and a helper failing its check twice is replaced by a stronger one.
Memory that survives. Decisions, progress, and open questions live in plain files on disk, so a crash or a restart costs you nothing.
Honest forecasting. Every estimate is a range with its confidence and the assumption most likely to move it, corrected by what actually happened.
Bad news first. A failed check leads the message instead of ending it, and any number nobody could verify carries that label beside it.
Decisions come to you. Choices arrive one at a time, recommended option first, with the tradeoff stated in plain words.
Risky moments stay yours. Sign-ins, payments, publishing, and deletions are prepared with their undo and handed back. It never types your credentials.

What that feels like in a conversation

This conversation is an illustration. The commands, the questions and the gates are real; these five bubbles were composed for this page, not recorded from a session. The full worked project is in the book.

You/brotherme-start I run a bakery. I want a website: our story, photos, hours, and cake pre-orders.
BrotherMEPre-orders is the one decision that changes everything else. When someone orders a cake, what should happen? A) you get an email (recommended, works day one), B) they pick a pickup slot, C) they pay online.
YouEmail. We confirm by phone anyway.
BrotherMEBad news first: one check failed. The gallery's third photo links to nothing when tapped. Fixing now, and the fix re-runs the same check.
BrotherMEThe re-run passed, so this is delivered. The packet lists what was built, every check that ran after the last change, and what I left out on purpose.

Get it, update it, go deeper

Get it. The two install lines at the top of this page, then /brotherme-help to confirm. To remove it, /plugin uninstall brotherme leaves your projects and records untouched.
Update it. Type /brotherme-update. It compares your version against the newest release and walks you through the update in plain words, whichever way you installed.
Go deeper. The book, sixteen chapters from install to expert use, is docs/book/brothermode-for-dummies.html in the repository (download it, then open it; it is one self-contained file). The philosophy, and the laws behind every mechanism above, live there in full.
Read the source. Everything is in one repository: github.com/khalilmaaouni/BrotherModeUp. QUICKSTART walks you through a first project, KNOWN-LIMITS is the long honest list.
