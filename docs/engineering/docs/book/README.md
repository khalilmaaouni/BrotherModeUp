# Booklet

The official BrotherMode booklet remains the long-form visual explanation of the product.

In this repository the booklet lives at:

```text
docs/book/brothermode-solo-builder-booklet.html
```

Direct link: [`../../../book/brothermode-solo-builder-booklet.html`](../../../book/brothermode-solo-builder-booklet.html)

The standalone zip of this documentation pack ships its own copy of the same file.

Use the booklet for:

- product framing;
- visual explanation;
- the problem BrotherMode is designed to solve;
- deeper conceptual understanding.

Do not use the booklet as the first-run developer guide.
