Deliberately not in this release

Each of these serves the north star and none is dropped. They are deferred by your decision that the foundation gets fixed first, and they are named here so the deferral is on the record rather than a silence.

Work governor · runtime capability probe · acceptance contracts frozen before implementation · independent verifier with an information boundary · convergence engine · reconciler for stranded state · preview lane with screenshots · cockpit generated from ledger events · memory retrieval evaluation · growing the benchmark · ten external builders.

The last one is the honest blocker on the whole positioning: nobody has counted whether the product makes work better. That closes with measurement, not with features.

The tick contract. A box ticks only when its done-check ran after the last edit and that output is quoted in the monospace line beside it. Percentages count ticked records, never impressions. A box with a plan but no run stays open.

What this page does not know. Whether the eleven branches conflict with each other: each was measured against main only. Whether merging the continuity branch turns eleven failing tests green: nobody has run it, which is why the rehearsal is its own step. How large the effect-class registry will be: its inventory is still running. Whether the audit will change the release scope: by construction it might, which is why it runs before the tag and not after.
