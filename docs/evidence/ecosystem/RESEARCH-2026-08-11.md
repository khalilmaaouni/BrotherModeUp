# Ecosystem research for the honest comparison page, 2026-08-11

This file gathers verified, dated evidence about six competing or adjacent
coding-agent tools, for a public page that puts BrotherMode beside them
fairly. Every factual claim below carries the URL of a page actually opened
and read on 2026-08-11 (not a search snippet). Where a load-bearing claim was
checked against a second independently-opened source, that is stated inline;
where only one source exists, that is stated in the same sentence, per the
evidence rules this file was written under.

## Scope: six tools, not eleven, and why these six

The original brief named eleven tools. Founder direction on 2026-08-11 was to
scope down to six rather than publish eleven thinly-sourced sections: "fewer
tools covered properly beats eleven covered thinly." The six chosen are the
ones a person evaluating BrotherMode would most plausibly consider instead of
it or alongside it:

- **Claude Code**, because BrotherMode is a plugin for it. A reader has to
  know what the base tool already does on its own before judging what
  BrotherMode adds.
- **GitHub Copilot** (CLI and coding agent), the largest install base and the
  tool most readers already have.
- **Cursor**, the leading AI-first editor and the most common "switch editor"
  alternative.
- **OpenAI Codex CLI**, the direct CLI-agent competitor from the other major
  lab, closest in shape to Claude Code itself.
- **Cline**, the closest open-source, editor-native peer running the same
  single-session, human-approval model BrotherMode assumes.
- **superpowers and the Claude Skills ecosystem**, the closest methodology
  peer, running on the exact same Claude Code runtime as BrotherMode, so the
  most direct combine-or-replace comparison.

Dropped for this pass, not because they are unimportant: OpenHands, Aider,
Devin, GitHub Spec Kit, and OpenSpec. Research on OpenHands and Aider was
gathered in this session and is available on request, but is not carried into
this file since it falls outside the six-tool scope the founder set.

## 1. Claude Code (Anthropic)

**What it is.** Anthropic's command-line and IDE coding assistant that reads
your codebase, edits files, and runs commands on your machine when you
describe what you want in plain language. Quoted from
https://code.claude.com/docs/en/overview (fetched 2026-08-11): "Claude Code is
an agentic coding tool that reads your codebase, edits files, runs commands,
and integrates with your development tools."

**What it is genuinely best at.** The broadest first-party surface and
extensibility of any tool in this set: one engine runs across terminal, VS
Code, JetBrains, a desktop app, and the web, and ships hooks, skills,
subagents, plugins, MCP, and an Agent SDK for building custom agents on top of
it, all from the same codebase. Source: https://code.claude.com/docs/en/overview,
double-sourced within this research effort (fetched independently twice,
matching).

**Stated scope or non-goals.** No dedicated non-goals page exists. The
closest is a permissions statement, single-sourced: "Claude Code only has the
permissions you grant it. You're responsible for reviewing proposed code and
commands for safety before approval." Source:
https://code.claude.com/docs/en/security (fetched).

**Licence and pricing.** Not open source. The public GitHub repo ships install
scripts, docs, and plugins, not the compiled agent; LICENSE.md states
"Anthropic PBC. All rights reserved. Use is subject to Anthropic's Commercial
Terms of Service." Source: https://github.com/anthropics/claude-code/blob/main/LICENSE.md
(fetched). Pricing, read from https://claude.com/pricing on 2026-08-11 and
double-sourced (fetched independently twice with matching figures): the Free
plan does not include Claude Code; Pro is $17/month billed annually; Max plans
start "from $100/month" for 5x usage, more for 20x; Team seats are $20 to $25
per seat per month (Standard) or $100 per seat per month (Premium), all
including Claude Code; Enterprise is seat price plus usage at API rates.

**Concrete handoff seam.** Claude Code is an MCP client, so an external tool
(Jira, Slack, Figma, a custom server) can be pulled into a session, and
separately ships a documented GitHub Actions integration (`claude-code-action`)
that runs on `@claude` mentions or a cron schedule, authenticates from repo
secrets, and pushes commits or opens a pull request on a git branch. This is
the exact seam BrotherMode itself already builds on: BrotherMode is a Claude
Code plugin wired into this same hooks and skills mechanism. Sources:
https://code.claude.com/docs/en/mcp and https://code.claude.com/docs/en/github-actions
(both fetched).

**Where it beats BrotherMode.** Claude Code needs no setup beyond installing
it: no fence hooks, no state files, and it updates itself. That is a real
tradeoff, already conceded in BrotherMode's own comparison page: "does better
than BrotherMode at raw flexibility... it carries none of the governance
overhead this project asks a session to pay on every write" (docs/market/CATEGORY.md,
this repository).

## 2. GitHub Copilot (CLI and coding agent)

**What it is.** Microsoft and GitHub's AI coding assistant, available as
in-editor autocomplete and chat, a terminal CLI, and a "coding agent" that
works a GitHub issue in the background and opens a pull request on its own.
Sources: https://docs.github.com/en/copilot/about-github-copilot/what-is-github-copilot
and https://docs.github.com/en/copilot/concepts/agents/about-copilot-cli (both
fetched). Naming note: the older `gh copilot` suggest and explain extension
was deprecated on October 25, 2025 in favor of the current Copilot CLI, per
https://github.com/github/gh-copilot (fetched), cross-checked against a
GitHub changelog entry dated 2026-01-21 (double-sourced, both GitHub-primary).

**What it is genuinely best at.** Handing off well-scoped, bounded background
tasks (bug fixes, dependency bumps, targeted refactors, added test coverage)
asynchronously while a developer works elsewhere. The coding agent runs in "a
GitHub Actions-powered environment" with "its own ephemeral development
environment" and returns a reviewable diff and PR rather than an interactive
session. Source: https://docs.github.com/en/copilot/concepts/agents/coding-agent
(fetched).

**Stated scope or non-goals, quoted.** The clearest, most explicit non-goals
statement of any tool in this review: "It's important to note that they were
not designed for every possible scenario." Coding agent specifically "can only
make changes in the repository specified when you start a task," "can only
work on one branch at a time," has "a maximum execution time of 59 minutes,"
and "only works with repositories hosted on GitHub." Sources:
https://docs.github.com/en/copilot/concepts/agents/coding-agent and
https://docs.github.com/en/copilot/responsible-use/agents (both fetched).

**Licence and pricing.** Not open source. The CLI's public repo ships under a
proprietary EULA, the "GitHub Copilot CLI License," which permits running it
but forbids modifying it or creating derivative works. Source:
https://github.com/github/copilot-cli/blob/main/LICENSE.md (fetched).
Pricing, read from https://github.com/features/copilot/plans on 2026-08-11
and double-sourced (fetched independently twice with matching figures): Free
is $0/month with 2,000 completions and 50 chat requests; Pro is $10/month with
unlimited completions; Pro+ is $39/month with access to premium models
including Opus; Max is $100/month for "sustained, high-volume agent
workflows." Coding-agent delegation is gated to Pro+ and Max. Exact
Business/Enterprise per-seat pricing was not confirmed on GitHub's own page in
the time available; see "What I could not verify."

**Concrete handoff seam.** Coding agent reads MCP tool configuration set as
JSON in a repository's own GitHub settings panel, and otherwise works through
GitHub's native Issues, branch, and PR model, so assigning an issue to
Copilot is itself the handoff. Its MCP support is the most restricted of the
six tools reviewed: its own docs state it does "not currently support
resources or prompts provided by the MCP server" (tools only), and does "not
currently support remote MCP servers that leverage OAuth for authentication
and authorization." Source:
https://docs.github.com/en/copilot/concepts/agents/coding-agent/mcp-and-coding-agent
(fetched).

**Where it beats BrotherMode.** Coding agent runs entirely in GitHub's own
cloud: no local machine, no local Claude Code session, and no locally
installed governance layer required at all. For a team that already lives in
GitHub Issues, that is strictly less setup than installing and configuring
BrotherMode on a local Claude Code install.

## 3. Cursor

**What it is.** A standalone code editor, a fork of VS Code, with an AI agent
built into it that can read, write, run, and test code across a project.
Source: https://cursor.com/ (fetched): "your coding agent for building
ambitious software."

**What it is genuinely best at.** A polished, all-in-one IDE experience that
bundles frontier models from multiple vendors (Anthropic, OpenAI, Google) in
one place, plus parallel and background agents, inline diffs, and
checkpoints, all inside one editor a non-CLI person can just open and use.
Sources: https://cursor.com/ and https://cursor.com/docs/agent/overview (both
fetched). This framing traces only to Cursor's own site and docs; no
independently-fetched third-party review was opened to confirm it, so it is
single-sourced to the vendor.

**Stated scope or non-goals, quoted.** "Checkpoints are stored locally and
separate from Git. Only use them for undoing Agent changes; use Git for
permanent version control." Source: https://cursor.com/docs/agent/overview
(fetched, single-sourced; no broader non-goals page was found).

**Licence and pricing.** Cursor is widely reported as proprietary, a closed
fork of VS Code, but in this research that specific claim traces only to a
third-party blog found via search and not independently fetched, so it is
UNVERIFIED at the primary-source level (Cursor's own pages read here carry no
license statement). Pricing, read from https://cursor.com/pricing on
2026-08-11: Hobby is free with limited Agent requests; Pro is $20/month;
Pro+ and Ultra add usage multipliers on top. Two independent fetches in this
research disagreed on the exact Pro+ and Ultra numbers (one read them as
multipliers off the $20 base, a second read flat monthly figures reported
elsewhere as $60 and $200), so treat Cursor's exact Pro+ and Ultra price as
unresolved; see "What I could not verify." Teams Standard is $40 per user per
month, Enterprise is custom.

**Concrete handoff seam.** Cursor is an MCP client over stdio, SSE, or
Streamable HTTP, so an external tool or server can be pulled into it, but it
does not expose its own MCP server, meaning the seam runs one direction only.
Source: https://cursor.com/docs/context/mcp (fetched). The durable handoff
surface for anything permanent remains git; Cursor's own docs are explicit
that local checkpoints are not a substitute for it.

**Where it beats BrotherMode.** Cursor needs no terminal literacy: install
the app, sign in, and the agent, the model choice, and the diff review are
all in one GUI. BrotherMode assumes a Claude Code terminal or IDE session
plus its own hook and store setup, a real barrier for someone who does not
want to touch a command line.

## 4. OpenAI Codex CLI

**What it is.** OpenAI's open-source coding agent that runs in your terminal,
reading and editing a local codebase from natural-language instructions.
Source: https://github.com/openai/codex (fetched): "Codex CLI is a coding
agent from OpenAI that runs locally on your computer."

**What it is genuinely best at.** A formal plan-then-execute separation (a
read-only plan mode that drafts a step-by-step plan before any file is
touched), a scriptable terminal loop built for CI use ("You work from the
terminal," "You need scripting or CI," "You want a local code review," "You
want to hand work to the cloud"), and being the only fully open-source agent
among the big-lab tools in this set. Source:
https://learn.chatgpt.com/docs/codex/cli (fetched).

**Stated scope or non-goals.** No explicit non-goals statement was found in
the pages read. This is a genuine documentation gap, not an unsearched claim.

**Licence and pricing.** Fully open source, Apache License 2.0: "Copyright
2025 OpenAI Licensed under the Apache License, Version 2.0." Source:
https://github.com/openai/codex/blob/main/LICENSE (fetched). This is a real,
load-bearing difference from Claude Code and GitHub Copilot, both proprietary.
Pricing, read from https://learn.chatgpt.com/docs/pricing.md on 2026-08-11 and
double-sourced (fetched independently twice with matching figures): Free is
$0/month; Go is $8/month; Plus is $20/month; Pro is "from $100/month" for 5x
usage, more for 20x; Business is $20 per user per month billed annually ($25
per month billed monthly); Enterprise and Edu are custom. A separate API-key
path bills "only for the tokens Codex uses, based on API pricing," a genuinely
usage-based alternative to the subscription tiers.

**Concrete handoff seam.** AGENTS.md, a plain-text instructions file Codex
reads automatically, merged across tiers: a global `~/.codex/AGENTS.md`, then
every directory from the git root down to the working directory. A spec
written by any process, human or another tool, becomes Codex's working brief
the moment it is dropped into the tree. Codex is also an MCP client
(`codex mcp add`, or `[mcp_servers.<name>]` in `~/.codex/config.toml`) over
local stdio or remote Streamable HTTP. Sources:
https://learn.chatgpt.com/docs/agent-configuration/agents-md and
https://learn.chatgpt.com/docs/extend/mcp (both fetched). A claim that Codex
can also act as an MCP server itself (`codex mcp-server`) appeared only in
secondary sources in this research and was not confirmed against a primary
OpenAI doc page, so it is UNVERIFIED.

**Where it beats BrotherMode.** Codex CLI's plan mode and AGENTS.md
convention are open and forkable: anyone can read the Apache-2.0 source and
adapt it. BrotherMode's enforcement, by contrast, is shaped to one specific
hook surface on one specific runtime (Claude Code) and, per BrotherMode's own
docs, does not even fire correctly on Codex's own exec path
(docs/mistakes/M19-the-codex-fence-does-not-fire-in-exec-mode.md, this
repository, referenced in README.md).

## 5. Cline

**What it is.** A free, open-source AI coding agent that runs as an extension
inside VS Code (also available as a CLI and an SDK), reading and editing
files and running terminal commands using a model API key the user supplies.
Sources: https://cline.bot/ and https://docs.cline.bot/ (both fetched).

**What it is genuinely best at.** A deliberate "think before you act"
workflow paired with the widest bring-your-own-key model choice of any tool
reviewed here: its own docs list 30 or more named providers on top of a core
set (Anthropic, OpenAI, Google, AWS Bedrock, Azure, OpenRouter), so a team is
never locked into one vendor's model. Sources:
https://docs.cline.bot/provider-config/other-30-plus-providers and
https://docs.cline.bot/sdk/model-providers (both fetched). This is a
stronger, more specific figure than an earlier internal note that only
claimed "more than two dozen," which this research corrects upward.

**Stated scope or non-goals, quoted.** "Plan mode is where you and Cline
figure out what you're building and how. In this mode, Cline can read your
codebase, run searches, and discuss strategy, but cannot modify any files or
execute commands." Source: https://docs.cline.bot/features/plan-and-act
(fetched), cross-checked against an independent third party, DeepWiki's
write-up of the same mechanic (double-sourced).

**Licence and pricing.** Apache 2.0, open source, confirmed on both
https://cline.bot/ and https://github.com/cline/cline (both fetched
independently, double-sourced). Cline itself carries no subscription fee;
cost is entirely the model API key the user brings. No separate Cline-hosted
subscription pricing page was found in this research. A correction to an
earlier internal claim: "human approval at every step" is not an absolute in
Cline. Approval is the default, but Cline ships an opt-in "Auto Approve"
feature letting a user bypass approval per action type, so it is
approval-by-default with a configurable escape hatch, not an invariant.
Source: https://docs.cline.bot/features/auto-approve (fetched).

**Concrete handoff seam.** Cline is an MCP client: "Users can connect Model
Context Protocol servers to access databases, APIs, and cloud infrastructure,
plus use community-built servers or request custom tools." It also ships as
an SDK and a CLI, both explicit programmatic and CI handoff surfaces beyond
the editor extension. Source: https://github.com/cline/cline (fetched).

**Where it beats BrotherMode.** Cline is itself fully open source (Apache
2.0), so anyone can audit, fork, or extend its enforcement logic directly,
and its "explicit approval" gate is a first-class, built-in mechanic rather
than an add-on hook a user has to wire up. Both are real differences from
BrotherMode, which is a layer of rules and hooks sitting on top of a closed
runtime.

## 6. superpowers and the Claude Skills ecosystem

Two related but distinct things: Anthropic's official Agent Skills mechanism
in Claude Code, and obra/superpowers, the most-used community skills package
built on top of it.

**What it is.** Agent Skills is Claude Code's official way to package a
reusable procedure, a markdown instructions file plus optional scripts, that
Claude loads only when it is relevant. superpowers is a free, community-built
library of such skills implementing a specific development methodology (test-
driven development, systematic debugging, structured code review) on top of
that mechanism. Sources: https://code.claude.com/docs/en/skills and
https://github.com/obra/superpowers (both fetched).

**What it is genuinely best at.** Skills' own strength is progressive
disclosure: only a skill's name and one-line description, roughly 100 tokens,
sit in context until it is triggered, so a project can carry dozens of long
procedures at near-zero ongoing cost. Quoted from
https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview
(fetched): "Progressive disclosure ensures only relevant content occupies the
context window at any given time." superpowers' own strength is enforcing one
specific, opinionated practice, refusing code written before a failing test
exists, more strictly than a general-purpose tool asks for by default, and it
is the most widely adopted third-party skill pack for Claude Code: 270,311
stars and 24,163 forks, read from the GitHub API on 2026-08-11 (single
source, GitHub is the sole authority on its own star count).

**Stated scope or non-goals.** "Skills are reusable, filesystem-based
resources that give Claude domain-specific expertise... Unlike prompts
(conversation-level instructions for one-off tasks), Skills load on demand."
Source: https://code.claude.com/docs/en/skills (fetched). No dedicated
non-goals statement was found for either Skills or superpowers; a genuine
gap, not an unsearched claim.

**Licence and pricing.** The Skills format itself follows "the Agent Skills
open standard," per https://code.claude.com/docs/en/skills (fetched), an
open specification, though the underlying agentskills.io standard page itself
was not independently opened in this research, so that governance detail is
UNVERIFIED. Claude Code, the runtime skills run on, is proprietary as
described in section 1. superpowers is MIT licensed, confirmed both by
GitHub's API (license MIT, actively pushed as of 2026-08-08) and by its own
plugin.json declaring `"license": "MIT"` (double-sourced). Neither carries a
separate price; cost is whatever the underlying Claude Code session already
costs.

**Concrete handoff seam.** A skill folder becomes a full plugin the moment it
carries a `.claude-plugin/plugin.json` file: "it loads as a plugin named
`<name>@skills-dir`, so it can bundle agents, hooks, and MCP servers." Source:
https://code.claude.com/docs/en/skills (fetched). That is the literal
mechanism BrotherMode itself already is: a SKILL.md-based plugin bundling its
own hooks. superpowers is distributed the same way, through a plugin
marketplace (`/plugin marketplace add`, then `/plugin install`).

**Where it beats BrotherMode.** superpowers is free, MIT-licensed, and has an
active community of contributors and 270,000-plus stars behind it, a scale of
peer review and usage no single-founder project can match. It also enforces
one practice, test-first development, with a hard refusal of code before a
failing test exists, more strictly than BrotherMode's own broader law set
asks for by default. BrotherMode's own comparison page already concedes
exactly this tradeoff (docs/market/CATEGORY.md, this repository).

## Cross-cutting answer 1: documented plugin, skill, hook, or MCP mechanisms

All six tools have at least one third-party-targetable mechanism, but the
shapes differ:

- **Claude Code**: MCP client (https://code.claude.com/docs/en/mcp), Hooks
  (https://code.claude.com/docs/en/hooks-guide), Skills and Plugins
  (https://code.claude.com/docs/en/skills), Subagents
  (https://code.claude.com/docs/en/sub-agents), and an Agent SDK. The
  broadest set of the six.
- **GitHub Copilot**: MCP only, tools-only support (no resources or prompts),
  no hooks or skills-equivalent found in the docs read.
  https://docs.github.com/en/copilot/concepts/agents/coding-agent/mcp-and-coding-agent
- **Cursor**: MCP client only (stdio, SSE, Streamable HTTP), does not expose
  its own MCP server; also documents an Extension API for registering MCP
  servers programmatically. https://cursor.com/docs/context/mcp
- **OpenAI Codex CLI**: MCP client (`codex mcp add`), and AGENTS.md as an
  open, inspectable config and instructions file, since the CLI itself is
  Apache-2.0. https://learn.chatgpt.com/docs/extend/mcp
- **Cline**: MCP client, plus SDK and CLI surfaces for programmatic use.
  https://github.com/cline/cline
- **superpowers and Claude Skills**: the Skills format itself is the
  mechanism, and a skill can escalate into a full plugin bundling its own
  hooks and MCP servers. https://code.claude.com/docs/en/skills

## Cross-cutting answer 2: the stage vocabulary each project's own docs use

- **Claude Code**: descriptive rather than formally named stages, Claude
  "plans the approach, writes the code across multiple files, and verifies it
  works"; separately ships `/code-review` and `/security-review` skills and a
  VS Code "plan review" feature.
- **GitHub Copilot coding agent**: "Research phase," "Planning phase"
  (producing an "implementation plan"), "Coding phase," "Review phase,"
  summarized in its own docs as "research, plan, and iterate."
- **Cursor**: "Agent," "task," "tool calls," "checkpoints." No formal
  plan, spec, review, or verify pipeline was found in the pages read.
- **OpenAI Codex CLI**: the most explicitly staged of the six, "plan" (a
  dedicated plan mode), "implement," "review" (a dedicated `/review`
  command), and "verify."
- **Cline**: "Plan mode" and "Act mode" are the entire vocabulary, explore
  and discuss in Plan, execute in Act.
- **superpowers**: brainstorming, writing-plans, subagent-driven-development
  or executing-plans, test-driven-development, systematic-debugging,
  verification-before-completion, requesting-code-review or
  receiving-code-review, finishing-a-development-branch. Quoted skill names
  from https://github.com/obra/superpowers (fetched).

## What I could not verify

- Cursor's exact current Pro+ and Ultra prices. Two independent fetches in
  this research disagreed (one read them as multipliers off the $20 base,
  another read flat $60 and $200 figures from secondary sources). Needs a
  fresh direct read of cursor.com/pricing before any specific number is
  published.
- Cursor's proprietary and closed-source status. Widely believed true, but in
  this research it traces only to a secondary blog, not an opened primary
  Cursor statement.
- Claude Code's and superpowers' non-goals. Neither carries a dedicated
  non-goals or scope-limits page; stated here as a gap, not filled in from
  memory.
- Whether OpenAI Codex CLI can act as an MCP server itself (`codex
  mcp-server`), not just a client. Appeared only in secondary sources; the
  primary GitHub doc page was not independently opened in this pass.
- The Agent Skills open standard's own governance page (agentskills.io) was
  not independently opened, so the claim that Skills "follows" an open,
  cross-tool standard rests on Anthropic's own docs page alone.
- GitHub Copilot Business and Enterprise exact per-seat pricing was not found
  on GitHub's own plans page in the time available; a secondary aggregator's
  figures were seen but deliberately not carried into this file.
- None of the vendor pricing pages read here (Claude, GitHub Copilot, Cursor,
  OpenAI Codex CLI) carried a visible "last updated" date. Every price in
  this file should be read as a snapshot taken on 2026-08-11, not as a dated,
  stable citation, and should be re-checked before the public page ships if
  time has passed.
- Nothing in this file was hands-on tested. No session was actually run
  against any of the six tools; every claim here is documentation-derived,
  not behaviorally verified.
- OpenHands and Aider were researched in this session but are out of the
  six-tool scope this file covers; that material exists but is not included
  here.
